# C Pattern Programming Problems

A collection of C programming problems focused on nested loops, logic building,
and pattern printing.

## 📚 Topics Covered

- Square patterns
- Triangle patterns
- Pyramid patterns
- Diamond patterns
- Number patterns
- Character patterns
- Nested loops

## 🛠️ Requirements

- GCC compiler
- Linux, Ubuntu, or Windows with GCC

## ▶️ Compile and Run

```bash
gcc p1.c -o p1
./p1
